# Publicar o site no GitHub Pages (gratuito)

1. Crie um repositório público no GitHub (ex.: `neuromobs`).
2. Envie o CONTEÚDO desta pasta `site/` para a raiz do repositório
   (`index.html`, `o-que-mudou.html`, `styles.css`).
   Dica: coloque também o `.mcaddon` numa *Release* do repositório e
   aponte o botão "Instalar" para ela, se quiser download direto.
3. No repositório: **Settings → Pages → Source: Deploy from a branch →
   Branch: main / (root) → Save**.
4. Em ~1 minuto o site estará em `https://SEU-USUARIO.github.io/neuromobs/`.

Atualizar = enviar os arquivos de novo. Para adicionar GIFs/vídeos, crie
`media/` aqui e referencie nas páginas (instruções na própria página
"O que mudou?").
